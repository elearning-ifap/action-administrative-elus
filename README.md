# L’action administrative — v6.22.2

Version autonome destinée à GitHub Pages.

## Publication

1. Déposer `index.html` et `.nojekyll` à la racine du dépôt ou du dossier publié.
2. Dans GitHub : Settings → Pages.
3. Choisir la branche et le dossier de publication souhaités.
4. Ouvrir l’URL GitHub Pages générée.

Cette version est distincte du package SCORM destiné à Moodle.
